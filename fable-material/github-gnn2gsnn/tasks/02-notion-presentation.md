# 任务 02：在 Notion 上做一份看得懂的讲解（给 Gemini）

## 前提

**任务 01 的 PR 合并之后再开始。** 这份讲解的每一个事实都必须来自 `literature/` 下已核实的条目，不能自己另外发挥。

## 读者是谁

读者只有一位：项目所有者。请按下面的画像来写。

- 不是这个领域的研究者，自己说过"不太懂这个项目具体在做什么"。
- 需要靠这份材料做判断：这个方向值不值得投入、先做哪篇论文、Claude 的建议靠不靠谱。
- 中文阅读。专业词可以出现，但第一次出现时必须解释。

检验标准：**读者读完每一页，能用自己的话向别人复述这一页讲了什么。**

## 页面结构

在 Notion 里建一个总页面，下面按顺序放这些子页面。

| 顺序 | 页面 | 要回答的问题 |
| --- | --- | --- |
| 0 | 一页读懂 | 这个方向在做什么、为什么有人做、现在卡在哪。不超过一屏。 |
| 1 | 基础概念 | 神经网络、图神经网络、脉冲神经网络、"转换"分别是什么。 |
| 2 | 时间线：转换技术 | 十年里一步步解决了什么。 |
| 3 | 时间线：脉冲图网络 | 别人在图上做到了哪一步。 |
| 4 | 时间线：视觉图模型 | 有哪些现成的强模型可以拿来转换。 |
| 5 | 时间线：只算变化的部分 | 视频和事件流上怎么省计算。 |
| 6 | 省电到底怎么算 | 能耗数字的来源、常见的不公平比较。 |
| 7 | 难点地图 | 每个难点是什么、谁解决了、哪里还空着。 |
| 8 | 可以做的论文 | 每个候选选题：要解决什么、为什么是空白、风险在哪。 |
| 9 | Claude 的判断哪里对、哪里错 | 来自 `literature/audit-of-claude-v1.md`。 |
| 10 | 术语表 | 全部专业词，一词一行。 |
| 11 | 文献库 | 用 Notion 数据库，一篇论文一条，字段对应任务 01 的固定格式。 |

## 每一页怎么写

1. **开头一句话说结论。** 先说这一页的要点，再展开。
2. **先打比方，再讲准确说法。** 比方后面紧跟一句"准确地说……"，并说明这个比方在哪里不成立。不要只留比方。
3. **一段只讲一件事**，每段不超过四行。
4. **每个概念配一个具体例子**，最好用同一张示例图片贯穿全篇，例如"一张猫的照片在每一步变成了什么"。
5. **每条事实后面标来源**，链接到文献库里对应的那一条。
6. **区分三种话**，用 Notion 的标注块（callout）加不同颜色：
   - 已核实的事实；
   - 作者或 Claude 的判断；
   - 还不知道、需要实验才能回答的问题。
7. **每页结尾放"三句话小结"和"读完应该能回答的两个问题"。**

## 图和动画

目标是让读者"看见"，不是装饰。每张图要能回答一个具体问题。

**必须做的图：**

| 图 | 要让读者看明白什么 |
| --- | --- |
| 一张图片怎么变成一张"图" | 图片切块、每块是一个点、相似的块连线 |
| 图网络的一次信息传递 | 一个点怎么从邻居收集信息 |
| 普通神经元和脉冲神经元的区别 | 一个一直输出数值，一个只在攒够了才发一下 |
| "转换"是什么 | 同一个网络，换了神经元，结果基本不变 |
| 时间步多少的影响 | 脉冲发得越多越准，但越费电 |
| 动态选邻居为什么可能出错 | 数值有一点误差，第 k 近和第 k+1 近的邻居就可能互换 |
| 视频里只算变化的部分 | 前后两帧大部分一样，只有变化处需要重算 |
| 三条时间线 | 每条线上的里程碑和它们解决的问题 |
| 难点地图 | 哪些已解决、哪些空着 |

**做法要求：**

- **优先自己画。** 用 Mermaid 图、SVG、或能嵌入 Notion 的小型交互网页都可以。动画适合用来展示"随时间变化"的过程，例如脉冲逐步累积、前后帧的差分。
- **引用论文里的图时**：不要把图片下载后重新上传。放论文链接，注明"见原文图 X"；确实需要展示时用 Notion 的嵌入或书签指向原始页面，并写清作者、年份、出处。
- **每张图下面写一句图注**，说明"这张图想让你看到的是……"。
- **不要用图来讲文献里没有的东西。** 示意图里的数字如果是编的，必须标"示意，非真实数据"。
- **动画要能暂停，并配一张静态图**，保证导出成文件后内容还在。

## 不能做的事

- 不能为了好懂而说错。拿不准的地方宁可写"这里比较复杂，简单说是……，细节见某篇"。
- 不能出现 `literature/` 里没有的论文、数字或结论。发现缺了什么，记到 `notion/gaps.md`，不要自己补。
- 不能替读者做决定。"可以做的论文"一页列出理由和风险，不写"应该做哪个"。
- 不能把 Claude 的草稿当成事实。草稿里的判断要标成"判断"，并附上核查结果。
