## Classification key (disposition of each review item in this ledger)

- **KEEP** — accept the item; apply its proposed fix at the named target.
- **REWRITE** — accept the problem, but the proposed fix text is wrong, incomplete, or in conflict; use the corrected repair in this row.
- **MOVE** — accept the item; the repair relocates content (destination named).
- **MERGE** — duplicate of another row; folded there, no separate action.
- **NARROW** — only a scoped part of the item stands; act on that part only (what is dropped is stated).
- **REMOVE_NONSCIENTIFIC** — no scientific defect; route to the copyedit pass (edit still made, no claim/evidence change).
- **BLOCK_EVIDENCE** — resolution requires evidence-layer work (packet-fact / artifact / registration repair); the default remedy (cut or downgrade the claim) is stated so the row is never unaddressed.

Every row carries a factual check performed against the frozen files (file:line or packet/artifact), not against the review text.
